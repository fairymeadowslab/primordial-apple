# Primordial Apple SDK

Primordial is the Apple Swift Package for the Primordial SDK alpha.

For installation, requirements, evaluation keys, examples, and API documentation, use the official docs:

https://fairymeadowslab.com/primordial/overview

This repository is intentionally kept small for Swift Package distribution.

## Requirements

Xcode 26.0+ with Swift 6.2+, iOS/iPadOS 17.0+, and macOS 14.0+. Apple’s Foundation Model requires OS 26+ and Apple Intelligence. See [full requirements](https://fairymeadowslab.com/primordial/getting-started#requirements).
